            The amount box is a calculator

            • 120*3 + 45 — arithmetic with + − × ÷ ^ ( )
            • 2.5k, 1.2m, 3b — thousands, millions, billions
            • 80 + 15% — adds 15% of 80 (tip & tax maths)
            • Type in either box — “They receive” works backwards too.
            • Pasting $1,299.00 or 1.299,00 € just works.

            Install it as an app

            • Chrome / Edge (desktop & Android): use the Install button in the top bar, or the install icon in the address bar.
            • iPhone / iPad (Safari): tap Share → Add to Home Screen.
            • Once installed it opens instantly and works offline with your last saved rates.
            • You’re opening this as a local file, so installing and offline mode are off. Serve the folder over http(s) — even localhost — to enable them.
